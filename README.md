# 🛡️ Чек-лист самопроверки ИИ-систем по Приказу ФСТЭК №117

## 📜 Описание проекта
Проект посвящен практическому применению больших языковых моделей (LLM) для перевода требований **Приказа ФСТЭК России №117 от 11.04.2025** (пункты 60, 61, 71) на язык IT-специалиста.

Приказ вступил в силу **1 марта 2026 года** и впервые вводит прямые требования к безопасности систем искусственного интеллекта в госсекторе. Главная проблема регуляторики — сложный юридический язык, непонятный разработчикам.

**Цель:** Создать инструмент для AI Risk Analyst, позволяющий провести экспресс-аудит корпоративной ИИ-системы за 30 минут вместо 4 часов.

## 🛠️ Инструменты и технологии
*   **Анализ регуляторики:** DeepSeek, Qwen (сравнительный анализ промптов).
*   **Веб-разработка:** HTML5, CSS3, JavaScript (GitHub Pages).
*   **Мультимедиа:** Аудио-гид (MP3), Видео-презентация (MP4).
*   **Документация:** PDF-отчет с детальным разбором промптов и скриншотами.

## 📊 Ключевые результаты
1.  **Совпадение требований:** 80% (4 из 5 пунктов идентичны у обеих моделей).
2.  **DeepSeek:** Лучше подходит для глубокого технического аудита (SHAP, adversarial attacks).
3.  **Qwen:** Лучше подходит для быстрого внедрения защитных механизмов (JSON Schema, DLP-фильтрация).
4.  **Чек-лист:** Включает 6 ключевых проверок: от защиты данных (п. 60) до сертификации ПО (п. 71).
